# wisprleaf
Voice-first LaTeX coding assistant vibe coded using Wispr Flow. 
Voice-first LaTeX dictation for mathematicians. Speak prose and equations, review the generated LaTeX with a rendered preview, do minimal edits and insert it into the Overleaf source editor.
Status - design review. No installable build yet.

IMPLEMENTATION_PLAN.md: open decisions, Phase 1 work breakdown and acceptance criteria, later phases
